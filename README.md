# AWS Floci Lab Coursework

Repository containing hands-on labs for AWS identity management, infrastructure automation, and cloud security simulation using Floci/LocalStack.

## Core Structure
- `configs/`: Environment configuration files.
- `labs/`: Individual lab instructions and tracking.
- `policies/`: AWS IAM policy JSON documents.
- `screenshots/`: Diagnostic and verification evidence.
- `scripts/`: Environment setup, cleanup, and utility verification scripts.
